# Фудграм: Платформа для публикации рецептов

## Описание проекта

**Фудграм** — это веб-приложение, предназначенное для публикации, хранения и обмена кулинарными рецептами. Пользователи могут:

- Создавать и редактировать свои рецепты.
- Добавлять рецепты других пользователей в избранное.
- Подписываться на публикации авторов.
- Формировать список покупок для выбранных блюд.

Проект состоит из фронтенда React и бэкенда REST API. Бэкенд обеспечивает аутентификацию пользователей, управление рецептами, подписками и списками покупок.

## Установка

1. **Клонирование репозитория:**
  ```bash
  git clone https://github.com/OsipovaDM/foodgram-st.git
  cd foodgram-st
  ```

2. **Развертывание с Docker:**
  - Находясь в корневой папке проекта запустите:
    ```bash
    docker compose up --build
    ```
  - После запуска контейнеров в новом терминале примените миграции
    ```bash
    docker exec foodgram-st-backend-1 python manage.py migrate
    ```
  - Загрузите стартовый набор данных в базу
    ```bash
    docker exec foodgram-st-backend-1 python manage.py loaddata data_fixtures.json
    ```
    Учетные данные суперпользователя: email - admin@mail.ru; password - admin
  - Выполните сбор статики
    ```bash
    docker exec foodgram-st-backend-1 python manage.py collectstatic
    ```
Проект доступен по адресу http://127.0.0.1:8000/

## Технологии
- **Бэкенд:** Django, Django REST Framework, Djoser
- **Фронтенд:** React
- **База данных:** PostgreSQL
- **Инфраструктура:** Docker, Nginx
